# スライドアップロード・逆質問機能

この版では、既存の質問投稿・質問整理・過去Q&A CSV機能を残したまま、次の機能を追加しています。

## 追加した機能

1. 発表者画面でスライドをアップロード
   - 対応形式: PDF / PPTX / PNG / JPG / JPEG / WEBP / TXT / MD / DOCX
   - PDF・画像は発表者画面と聴衆画面にそのまま表示されます。
   - PPTX / DOCX は中のテキストを抽出してAI入力に使います。
   - PPTXをブラウザ上でスライド見た目のまま表示したい場合は、PDFに変換してアップロードしてください。

2. 聴衆画面に現在スライドを同期表示
   - 聴衆画面は5秒ごとに現在スライドを取得します。
   - 発表者が新しいスライドをアップロードすると、聴衆側にも反映されます。

3. 発表者が任意のタイミングで逆質問を生成
   - 発表者画面の「逆質問を生成して聴衆に表示」ボタンで実行します。
   - スライドの抽出テキスト、補足メモ、聴衆から集まった質問をもとに、理解が浅そうな部分を確認する逆質問を生成します。
   - OPENAI_API_KEY が未設定の場合は、デモ用のモック逆質問を表示します。

4. 聴衆が逆質問に回答
   - 聴衆画面に逆質問が表示され、短文で回答できます。
   - 発表者画面には回答一覧が表示されます。

## OpenAI API を使う場合

`.env` に以下を設定してください。

```env
OPENAI_API_KEY=sk-ここに自分のAPIキー
OPENAI_MODEL=gpt-4o-mini
```

`OPENAI_MODEL` は省略できます。

## 実行方法

```bash
npm install
npm start
```

ブラウザで以下を開きます。

```text
http://localhost:3000
```

発表者画面からスライドをアップロードし、聴衆画面を別タブまたはスマホで開くと同期表示を確認できます。

## 追加・編集した主なファイル

- `server.js`
  - スライドアップロードAPI
  - スライドテキスト抽出
  - 逆質問生成API
  - 逆質問回答API

- `public/presenter.html`
  - スライドアップロード欄
  - 現在スライド表示欄
  - 逆質問生成・配信欄
  - 逆質問回答一覧

- `public/audience.html`
  - 現在スライド表示欄
  - 逆質問表示・回答欄

- `public/script.js`
  - スライド同期
  - 逆質問生成
  - 逆質問回答送信

- `public/style.css`
  - スライド表示・逆質問UIのスタイル

- `package.json`
  - `multer`, `pdf-parse`, `mammoth`, `adm-zip` を追加
